# Poké Gauntlet — Can You Go 13-0?

Draft 6 random Pokémon from gens 1-8 and beat all 8 Gym Leaders, the Elite Four,
and the Champion without losing. Inspired by 82-0.com.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
**Option A — CLI:**
```bash
npm i -g vercel
vercel        # follow prompts, accept defaults (Vite is auto-detected)
vercel --prod
```

**Option B — GitHub:**
1. Push this folder to a GitHub repo
2. Go to vercel.com → Add New Project → Import the repo
3. Framework preset: Vite (auto-detected) → Deploy

The share link/image footer auto-uses your deployed domain — no config needed.
